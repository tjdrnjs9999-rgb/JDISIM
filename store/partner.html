🔑 API (자체 시스템 연동)

키는 반드시 헤더(x-jd-pkey)로 전송하세요. URL에 키를 넣지 마세요.
curl -X POST "https://jdisim-proxy.vercel.app/api/esim?action=partner_issue" \ -H "Content-Type: application/json" -H "x-jd-pkey: 발급받은키" \ -d '{"code":"JD-JPSB2G-05","phone":"01012345678","buyer":"김여행"}' # 목록: action=partner_orders / 견적: partner_quote {code} # 취소: partner_cancel {tok} / 가격표: partner_pricelist

📄 정책

· 발주(고객 발급 클릭) 후에는 취소·환불이 불가합니다 — 대기 상태만 취소 가능
· 발급 후 고객 케어(설치·사용량 조회·문의)는 본사 케어링크가 담당합니다
· 발급 실패 시 차감액은 자동 환급됩니다 (정산 탭에서 확인)
