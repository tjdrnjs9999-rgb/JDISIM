2. 이 사업의 구조 — 돈이 도는 방식

1
충전 — 선불금을 충전합니다. 이 돈은 전부 상품(eSIM) 매입에 쓰입니다.
2
판매 — 내 스토어에서 고객이 eSIM을 구매합니다. 판매가는 파트너가 정합니다(권장가표 제공).
3
발급 — 포털에서 고객 이름·전화만 입력하면(또는 API 연동 시 자동) 고객에게 발급 알림톡이 나갑니다.
4
차감 — 고객이 알림톡의 "발급하기" 버튼을 누르는 순간 eSIM이 발급되고, 그때 공급가가 잔액에서 차감됩니다.
5
수익 — (내 판매가) − (공급가) − (마켓 수수료) = 내 마진. 정산은 포털에서 실시간 확인.
💡 핵심: 고객이 버튼을 누르기 전엔 돈이 안 나갑니다. 재고·선매입 부담이 없는 이유입니다.

3. 포털 사용법

🎫 발급하기

  1. 상품코드 입력 → 상품 조회 (상품명·공급가·잔액 확인)
  2. 고객 이름 + 휴대폰 번호 입력 (이메일은 선택)
  3. 발급하기 클릭 → 고객에게 파트너님 카카오 채널로 알림톡이 1분 내 자동 발송됩니다 (8장 연동 완료 시)
  4. 알리고 미연동 상태에서는 발급링크가 생성되며, 직접 카톡·문자로 전달하면 됩니다

📦 주문 내역

  • 발급대기 — 고객이 아직 버튼을 안 누름 (차감 전, 취소 가능)
  • 발급완료 — eSIM 발급·차감 완료 (취소 불가)
  • 링크 복사 버튼으로 고객에게 재전달 가능

🧾 정산

  • 월별 발급·충전 내역 확인, 정산서 CSV 다운로드
  • 잔액이 부족하면 발급이 거절됩니다 — 미리 충전해 두세요

4. 발급·취소 규칙 (중요)

상황취소비고
고객이 발급 버튼을 누르기 전✅ 가능주문 내역에서 [취소] — 차감 없음
고객이 발급 버튼을 누른 후❌ 불가eSIM이 이미 발급됨 (통신사 정책)
⚠️ 고객 변심 환불은 발급 전에만 안전합니다. 스토어 상품 페이지에 "QR 발급 후 교환·환불 불가" 문구를 반드시 넣으세요 (제공되는 상세페이지에는 포함돼 있습니다).

5. 고객 CS는 이렇게

  • 고객이 받는 알림톡에는 발급 버튼 + 사용량 조회(케어링크)가 들어 있습니다 — 설치 안내·잔여량 확인은 그 페이지가 대신합니다
  • "설치가 안 돼요" → 케어링크 안의 설치 가이드(아이폰/갤럭시)로 안내
  • "데이터가 안 터져요" → ① 데이터 로밍 ON ② 기존 유심 데이터 OFF ③ 재부팅 — 이 3가지로 대부분 해결
  • 해결이 안 되는 기술 문제는 파트너 카톡방으로 — 본사가 함께 봅니다

6. 금지·유의사항

  • 공급 원가·공급처 정보를 외부에 공개하지 마세요 (계약 위반)
  • API 키는 비밀번호입니다 — 유출 시 즉시 재발급 요청
  • 고객 개인정보(이름·전화)는 발급 목적 외 사용 금지
  • "무제한" 등 상품 표기는 제공된 상세페이지 문구를 그대로 사용하세요 (과장 광고 방지)

7. 자주 묻는 질문

Q. 고객이 알림톡을 못 받았대요

주문 내역에서 링크를 복사해 카톡·문자로 직접 보내주세요. 같은 링크입니다.

Q. 잔액이 부족하면?

발급이 거절됩니다(고객에게 아무것도 안 나감). 충전 후 다시 발급하면 됩니다.

Q. 어떤 상품부터 팔까요?

일본·베트남·유럽이 3대 볼륨입니다. 제공되는 국가별 상세페이지 순서대로 올리는 걸 권합니다.

Q. 가격은 어떻게 정하나요?

권장판매가표(공급가표와 함께 제공)를 기준으로, 마켓 수수료를 감안해 조정하세요.

8. 카카오 알림톡 연동 (내 채널로 발송)

고객이 받는 발급 알림톡은 파트너님의 카카오 채널 이름으로 나갑니다 — 고객 문의도 그 채널로 들어오니, 내 브랜드로 응대하는 구조입니다. 아래 순서대로 한 번만 세팅하면 됩니다 (약 1~2일, 심사 포함).

1
카카오톡 채널 개설 — business.kakao.com에서 채널 만들기 → 비즈니스 인증 신청(사업자등록증 필요, 1~2일 소요)
2
알리고 가입 — smartsms.aligo.in 회원가입(비즈니스 이메일 사용) → 발신번호 등록(통신서비스 이용증명원)
3
카카오 발신프로필 연동 — 알리고 [카카오알림톡] 메뉴에서 내 채널 검색 → 발신프로필 키(senderkey) 발급
4
템플릿 2종 등록 — 아래 두 문안을 글자 하나 바꾸지 말고 그대로 각각 등록해 심사받으세요(버튼 포함). 승인되면 템플릿 코드 2개(예: UB_1234, UB_1235)가 나옵니다
5
포털에 직접 입력 — 파트너 포털 [설정] 탭 → 💬 알림톡 (내 채널)에 ①알리고 API Key ②알리고 아이디 ③발신프로필 키(senderkey) ④발신번호 ⑤발급 템플릿 코드 ⑥발급완료 템플릿 코드 — 6가지를 입력하고 저장하세요. 저장 즉시 자동 발송이 켜집니다 (본사 확인 대기 없음)
✅ 영업 시작 조건: 템플릿 2종 승인 + 포털에 6가지 입력 완료 시점부터 판매를 시작합니다. 그 전에는 고객 알림톡이 나가지 않으니, 발급 화면의 링크를 직접 전달하셔야 합니다.
